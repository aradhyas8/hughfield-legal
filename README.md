# Hushfield Legal & Support

Static website for Hushfield's legal policies and support pages, hosted on GitHub Pages.

**Live site:** https://aradhyas8.github.io/hughfield-legal/

## Pages

- `/` — Home
- `/privacy/` — Privacy Policy
- `/terms/` — Terms of Use
- `/support/` — Help & Support

## Deployment

The site deploys automatically to GitHub Pages on every push to `main` via the workflow at `.github/workflows/deploy-pages.yml`.

### One-time setup

In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.
